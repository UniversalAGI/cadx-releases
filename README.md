# CADx releases

Official CADx downloads for macOS, Windows, and Linux.

- [All releases](https://github.com/UniversalAGI/cadx-releases/releases)
- [Nightly builds](https://github.com/UniversalAGI/cadx-releases/releases?q=nightly&expanded=true)

Choose the installer for your operating system and processor. Releases also include standalone command-line archives and SHA-256 checksums.

Nightly builds are prereleases. Current macOS builds are unsigned and require manual installation and updates. If macOS blocks the app, use **System Settings → Privacy & Security → Open Anyway**.

This repository distributes CADx release downloads. Product source code is maintained separately.
